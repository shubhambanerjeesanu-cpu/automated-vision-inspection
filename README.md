# Automated Industrial Vision Inspection System

A Python-based edge-detection pipeline designed for automated surface defect tracking and quality assurance verification.

## 🛠️ Project Features
- **Grayscale Normalization:** Strips color variance to optimize matrix processing latency.
- **Gaussian Noise Filtering:** Eliminates high-frequency surface background patterns.
- **Canny Edge Detection:** Traces sharp pixel transitions to locate physical anomalies such as dents and scratches.

## 💻 Tech Stack
- **Language:** Python 3.x
- **Core Library:** OpenCV (`cv2`)
